Capítulo 3Arquitectura general

La foto completa

Cuando alguien abre "Eggs App" desde el escritorio, Windows arranca un solo programa: EggsApp.Desktop.exe. Dentro de ese programa viven tres cosas a la vez:

  1. La ventana de Windows (proyecto EggsApp.Desktop, hecha con WPF). Es una ventana maximizada con un control WebView2 adentro, que funciona como un navegador sin barras.
  2. La API (proyecto EggsApp.Api, hecha con ASP.NET Core). Arranca dentro del mismo proceso, escuchando solo en 127.0.0.1 (la propia computadora, inaccesible desde la red) y en un puerto que Windows elige cada vez. Sirve dos cosas: las rutas /api/… y los archivos de la interfaz.
  3. La interfaz React (carpeta src/web). Se compila a archivos estáticos que se guardan en wwwroot. El WebView2 los pide a la API y los muestra.

Los datos se guardan en %LocalAppData%\EggsApp\eggs.db, un archivo SQLite. En una PC típica eso es C:\Users\<usuario>\AppData\Local\EggsApp\eggs.db.

Por qué está armada así

DecisiónRazón
Interfaz web dentro de una ventana, en vez de una ventana WPF puraReact permite hacer pantallas accesibles, grandes y bonitas con mucho menos trabajo, y se pueden probar automáticamente. WebView2 viene incluido en Windows 11.
Una API HTTP aunque todo esté en la misma PCSepara claramente la interfaz de las reglas del negocio. La misma API se puede correr sola para desarrollo, con Swagger, y en el futuro podría servir a una versión móvil.
La API dentro del mismo proceso (no un servicio aparte)Un solo programa que abrir y cerrar. No hay servicios de Windows, ni puertos fijos que puedan chocar con otro programa.
Puerto elegido por el sistema (puerto 0)Nunca choca con otro programa. Consecuencia: la dirección de la página cambia en cada arranque, por eso la interfaz nunca usa localStorage, cookies ni IndexedDB: estarían vacíos cada vez.
SQLite en un archivo localSin instalar un motor de base de datos, sin costo, rápido para el volumen de una familia, y fácil de respaldar copiando un archivo.
Una sola copia del programa a la vezSi se abriera dos veces habría dos APIs escribiendo el mismo archivo. Un segundo intento de abrir solo trae al frente la ventana que ya está abierta (SingleInstance).
Solo escucha en 127.0.0.1 y valida el encabezado HostNinguna otra computadora puede conectarse, y una página web maliciosa no puede engañar al navegador para llegar a la API (protección contra "DNS rebinding").

Las capas, de arriba a abajo

Regla de oro: las reglas del negocio viven en el servidor

La interfaz revisa muchas cosas para ayudar al usuario (por ejemplo, que el precio no esté vacío), pero el servidor revisa todo otra vez y es el único que decide. Por ejemplo, el total de una venta lo calcula siempre el servidor y descarta cualquier total que le manden. Si alguna vez la interfaz y la API no coinciden, la que manda es la API.
