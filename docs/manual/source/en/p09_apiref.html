Chapter 9API reference

Every route starts with /api. Dates are always local YYYY-MM-DD text. Money is always a whole number of colones. To try them by hand, run the API on its own and open http://localhost:5080/swagger.

Error format

400 — data with errors (one Spanish message per field):

{ "errors": {
    "date": ["La fecha no puede ser futura."],
    "items[0].unitPrice": ["Escriba el precio por cartón."]
} }

409 — refused by a rule (a message to show as-is):

{ "message": "María todavía debe ₡8.000.
  Solo se puede borrar un cliente que
  esté al día." }

404 has no body: nothing active with that id.

Sales — /api/sales

MethodRouteWhat it doesResponses
GET/sales?from=&to=Sales between two dates (inclusive), newest first, with cashTotal and creditTotal.200, 400
GET/sales/last-pricesLast price per carton type: { "A": 2500, "B": 4800 }.200
GET/sales/{id}One sale with lines, customer, paidNow and owed.200, 404
POST/salesCreates a sale (body: SaleCommand).201, 400
PUT/sales/{id}Edits a sale (same body).200, 400, 404, 409
DELETE/sales/{id}Deletes the sale, its lines and its "paid with the sale" payment.204, 404, 409

Body of POST/PUT:

{
  "date": "2026-11-23",
  "isCredit": true,
  "customerId": "…guid…",           // or null; or instead:
  "newCustomer": { "name": "Rosa Mora", "phone": "8888-1234" },
  "paidNow": 2000,                   // credit only; less than the total; 0 = none
  "items": [ { "cartonType": "A", "quantity": 2, "unitPrice": 2500 },
             { "cartonType": "B", "quantity": 1, "unitPrice": 4800 } ]
}

Payments (abonos)

MethodRouteWhat it doesResponses
POST/customers/{customerId}/paymentsStandalone payment. Body: { date, amount, note }.201, 400, 404
POST/sales/{saleId}/paymentsPayment from "Abonar": today, toward that sale. Body: { amount }.201, 400, 404, 409
GET/sales/{saleId}/paymentsThe sale, how much has been paid on it (paid) and which part of which payment paid it, newest first.200, 404
GET/payments?from=&to=The period's payments and their total. Includes forSaleDate for "Abono a la venta del…".200, 400
GET/payments/{id}One payment.200, 404
PUT/payments/{id}Changes the date, amount and note (never the customer).200, 400, 404, 409
DELETE/payments/{id}Deletes a payment (the customer owes that much again).204, 404, 409

409 on PUT/DELETE: the payment was made with a credit sale (change it from the sale) or belongs to a deleted customer.
